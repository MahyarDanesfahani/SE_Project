# فهرست موارد باز و نواقص پروژه

این فایل مرجع کارهای انجام‌نشده، ناقص یا وابسته به تصمیم/مجوز بیرونی است. هیچ موردی که در این فهرست وضعیت `Blocked` یا `Planned` دارد نباید به‌عنوان قابلیت فعال معرفی شود.

## Blocked — نیازمند تصمیم یا دسترسی بیرونی

- اتصال واقعی تغذیه به `https://student.znu.ac.ir/`: نیازمند API/مجوز رسمی، روش احراز هویت، endpointهای منو/رزرو/لغو و حساب تست.
- اتصال گلستان: نیازمند API یا روش رسمی مجاز و سیاست نگهداری داده.
- اتصال خوابگاه: نیازمند داده مجاز، رضایت و قرارداد دسترسی.
- ربات بله: نیازمند مستندات و دسترسی عملیاتی API.
- ربات تلگرام عملیاتی: نیازمند توکن، سیاست اعلان و تأیید دامنه فرمان‌ها.
- Provider هوش مصنوعی: نیازمند انتخاب Provider، کلید محیطی، سقف هزینه و سیاست نگهداری مکالمه.
- قواعد رسمی معدل، انتخاب واحد، سقف واحد و شرایط خاص: نیازمند تأیید دانشگاه.

## Planned — نسخه اول یا نزدیک به آن

- RBAC پیشرفته، نقش‌های جزئی مدیر/کارشناس و پنل مدیریت محتوای رسمی.
- بازیابی رمز عبور، refresh token، لغو نشست‌ها و مدیریت دستگاه‌ها.
- Audit Log کامل برای ورود، تغییر نمره، رزرو، عملیات AI و مدیریت محتوا.
- CRUD کامل ویرایش/حذف برای امتحان و وظیفه.
- تقویم کلاس‌ها با تاریخ واقعی ترم و timezone/تقویم شمسی در رابط کاربری.
- ثبت وضعیت ظرفیت و آخرین همگام‌سازی گروه‌های درسی.
- نمایش دلیل حذف هر گروه از سناریو و امتیازدهی ترجیحات انتخاب واحد.
- ثبت تاریخچه تغییر نمره و نمایش اختلاف داده دستی/رسمی.
- اجرای migration و seed در محیط واقعی PostgreSQL.
- تست API، تست منفی مالکیت داده، تست E2E و تست فایل بزرگ/نامعتبر.
- اتصال کامل Frontend به همه APIها، مدیریت خطای فرم‌ها و route protection.
- نصب پایدار Frontend و تولید lockfile؛ نصب فعلی npm به شبکه وابسته است.
- اعلان‌های زمان‌بندی‌شده و جلوگیری از تکرار اعلان.
- وضعیت اتصال‌ها و پنل مدیریت Adapterها.

## Future — خارج از تحویل پایه

- OCR و پشتیبانی قالب‌های متعدد چارت.
- اپلیکیشن بومی موبایل.
- جامعه دانشجویی و تطبیق هم‌گروهی/هم‌اتاقی.
- تحلیل پیشرفته نظرسنجی و moderation کامل.
- همگام‌سازی خودکار چندمنبعی اطلاعیه‌ها.
- SSO دانشگاهی و onboarding چنددانشگاهی.
- Agent چندمرحله‌ای AI و شخصی‌سازی پیشرفته.

## وضعیت فعلی

- هسته Backend، migrationها و APIهای آموزشی پایه پیاده‌سازی شده‌اند.
- Frontend پایه، ورود/ثبت‌نام و داشبورد اولیه وجود دارد.
- اتصال واقعی بیرونی فعال نیست و داده آزمایشی باید با برچسب مشخص استفاده شود.
