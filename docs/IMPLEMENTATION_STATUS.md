# وضعیت پیاده‌سازی ZU Assistant

آخرین به‌روزرسانی: 2026-11-22

## فاز صفر — اسکلت و زیرساخت پایه

| حوزه | وضعیت | توضیح |
|---|---|---|
| Backend FastAPI | شروع‌شده | اپلیکیشن پایه و health endpoint ایجاد شده است. |
| Frontend Next.js | شروع‌شده | صفحه پایه فارسی و RTL ایجاد شده است. |
| PostgreSQL | آماده توسعه | سرویس Docker Compose اضافه شده است. |
| احراز هویت | پیاده‌سازی پایه | ثبت‌نام، ورود JWT و endpoint پروفایل فعلی اضافه شده است. |
| مدل داده و migration | پیاده‌سازی پایه | مدل‌های User، University و StudentProfile و migration اول اضافه شده‌اند؛ seed دانشگاه زنجان آماده است. |
| پروفایل دانشجو | پیاده‌سازی پایه | مشاهده و ویرایش پروفایل فقط برای کاربر احراز‌شده خودش فراهم است. |
| چارت درسی | پیاده‌سازی پایه | مدل چارت، درس، وضعیت درس، پیش‌نیاز و API ایجاد/مشاهده/افزودن درس آماده است. |
| ورود فایل چارت | Preview | CSV و XLSX با سقف حجم و اعتبارسنجی اولیه خوانده می‌شوند؛ ثبت نهایی هنوز نیازمند تأیید است. |
| تأیید چارت | پیاده‌سازی پایه | ردیف‌های معتبر Preview به‌صورت تراکنشی در چارت ذخیره می‌شوند. |
| تست | پایه | تست health موجود است؛ تست‌های کامل Identity بعد از آماده شدن محیط Python اجرا می‌شوند. |

## محدودیت‌های فعلی

- هنوز هیچ قابلیت محصولی مانند ثبت‌نام، انتخاب واحد یا چارت درسی پیاده‌سازی نشده است.
- اتصال به گلستان، تغذیه، خوابگاه، پیام‌رسان‌ها و AI فعال نیست.
- فایل‌های نیازمندی در ریشه پروژه نگهداری می‌شوند؛ راهنمای اجرایی پروژه در این مرحله اضافه شده است.
