# وضعیت پیاده‌سازی ZU Assistant

آخرین به‌روزرسانی: 2026-11-22

## فاز صفر — اسکلت و زیرساخت پایه

| حوزه | وضعیت | توضیح |
|---|---|---|
| Backend FastAPI | شروع‌شده | اپلیکیشن پایه و health endpoint ایجاد شده است. |
| Frontend Next.js | شروع‌شده | صفحه پایه فارسی و RTL ایجاد شده است. |
| PostgreSQL | آماده توسعه | سرویس Docker Compose اضافه شده است. |
| احراز هویت | شروع‌نشده | در فاز بعدی پیاده‌سازی می‌شود. |
| مدل داده و migration | شروع‌نشده | پس از تثبیت مدل Identity ایجاد می‌شود. |
| تست | پایه | یک تست API برای health endpoint اضافه شده است. |

## محدودیت‌های فعلی

- هنوز هیچ قابلیت محصولی مانند ثبت‌نام، انتخاب واحد یا چارت درسی پیاده‌سازی نشده است.
- اتصال به گلستان، تغذیه، خوابگاه، پیام‌رسان‌ها و AI فعال نیست.
- فایل‌های نیازمندی در ریشه پروژه نگهداری می‌شوند؛ راهنمای اجرایی پروژه در این مرحله اضافه شده است.
